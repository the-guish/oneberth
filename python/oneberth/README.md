# oneberth

Sign-in, sessions, tokens and roles, and the web application that neorc and
Robinauts share.

A base install brings no third-party code. Each adapter that needs some is an
extra: `oneberth[providers]`, `oneberth[postgres]`, `oneberth[web]`.

The specs are in the repository, under
[docs/specs](https://github.com/the-guish/oneberth/tree/main/docs/specs).
